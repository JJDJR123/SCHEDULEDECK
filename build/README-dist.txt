日程舱 · ScheduleDeck
=====================

双击「日程舱.exe」启动。界面会以一个独立的 Chrome / Edge 窗口打开，
不会有地址栏和标签页。关闭窗口后程序仍留在右下角托盘，
双击托盘图标可以再次打开。

第一次使用：导入你的飞书表格
----------------------------
点右上角「导入表格」，两种方式选一种。

【扫码登录 · 推荐】不需要把应用加成文档协作者
1. 开发者后台 → 你的应用 →「安全设置」→ 重定向 URL：
   添加 http://127.0.0.1:17899/callback
2. 「权限管理」加 offline_access、sheets:spreadsheet:readonly、
   wiki:wiki:readonly（用多维表格再加 bitable:app:readonly）
3. 回日程舱，填 App ID / Secret → 点「用飞书登录」→ 浏览器里扫码
4. 粘贴表格链接 →「读取这张表」

【应用凭证】需要把应用加成文档协作者
点击右上角「导入表格」，按弹窗里的 6 步操作：

1. 打开 https://open.feishu.cn/app 创建「企业自建应用」，名字随意。
2. 「添加应用能力」里打开「机器人」。
3. 「权限管理」只加这三个：
     sheets:spreadsheet:readonly   （电子表格，必加）
     bitable:app:readonly          （多维表格，按需）
     wiki:wiki:readonly            （知识库链接，按需）
   不要加 drive:drive:readonly：整个云盘只读属于高级权限，
   需要管理员审批，本应用用不到。
4. 「版本管理与发布」→ 创建版本 → 发布，可用范围勾上你自己。
5. 回到飞书表格页，右上角「···」→「添加文档应用」→ 选刚建的应用 → 可阅读。
   （知识库里的表格：知识库设置 → 成员设置 → 把包含该应用的群 / 应用加进去）
6. 回到日程舱，粘贴表格链接 + App ID + App Secret，点「连接并导入」。

不想建应用？用「粘贴 / 文件」标签页：
在飞书表格里 Ctrl+A、Ctrl+C，粘贴进日程舱即可（也可以导入 .csv 文件）。
缺点是每次表格更新要重新粘贴。

用起来
------
· 左侧切换 总览 / 任务清单 / 日历 / 表格 / 规则中心
· 点任务卡片看详情，可以标记完成、设置单独提醒、稍后提醒
· 「规则中心」里自定义：剩余多久标红 / 标黄、已完成怎么显示、标签文字、颜色
· 右上角搜索框支持标题、标签、备注、负责人；回车下面的筛选条可以叠加
· Ctrl+K 快速搜索，Esc 关闭弹层

数据与隐私
----------
data\state.json    任务、完成状态、规则、设置
data\config.json   App ID / App Secret 与上次导入的链接（只在本机，不上传）
data\browser\      应用窗口使用的浏览器配置
data\server.log    后台服务日志

提醒
----
· 到点会弹 Windows 通知，并播放提示音；应用内也会出现带「标记完成 / 稍后 10 分钟」的提示条
· 首次使用请到「提醒中心」点「开启」，允许浏览器通知
· 提醒依赖页面运行：窗口关掉后提醒会停止，重新打开即可

卸载
----
退出托盘图标后，直接删除整个文件夹。
