# 建议

来自使用者的建议，**按人分文件夹**，**纯文本**：

```
建议/
  杨浩源/
    2026-10-22T01-05-33-120Z.txt
  张三/
    ...
```

每个文件长这样（前三行是元信息，`---` 之后是正文）：

```
# 来自：杨浩源
# 时间：2026/10/22 01:05:33
# 版本：1.0.20261022010533
# 机器：DESKTOP-XXXX
---
想解决什么……
现在怎么做的……
希望变成什么样……
```

## 怎么从 app 收进来

点右上角「我有个想法🤓👆」提交，文件会先落在本机：

```
<exe 同级>\data\suggestions\<账号名>\<时间戳>.txt
```

名字自动取当前登录的飞书账号，不用手填。

攒够了在仓库里跑一次：

```powershell
powershell -File tools\collect-suggestions.ps1
```

它会把 `打包成品\data\suggestions\*` 复制到这里（同名覆盖），然后 commit 就行。

## ⚠️ 公开仓库前请先删掉本文件夹里的内容

建议正文很可能涉及公司内部信息（排期、人名、表结构）。如果这个仓库要公开：

```powershell
# 只保留 README
Get-ChildItem 建议 -Directory | Remove-Item -Recurse -Force
git add -A; git commit -m "chore: 清空建议内容（仓库转公开）"
```

而且**已经提交过的历史里也有**，公开前要么重写历史，要么换一个新仓库。
